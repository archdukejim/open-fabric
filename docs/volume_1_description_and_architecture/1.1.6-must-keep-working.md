## 1.1.6.1 Both architectures, within the memory budget

arm64 and amd64 (2.1.1.11): check that every new image publishes both (`docker buildx imagetools inspect <image>`).
Mind the memory budget of a 4 GB Raspberry Pi (2.1.2.3, 1.2.6) and set a limit for every new container. Moved from
`AGENTS.md` §5 on 2026-10-03.

## 1.1.6.2 Offline

Any feature that fetches something has an offline path — a bundle, a local registry or a local mirror (2.1.1.22).

## 1.1.6.3 Idempotent

Every install, seed or configure step can be re-run safely and converges (global Rule 12).

## 1.1.6.4 Upgrades of existing installs

Re-running setup on a live host must work, never only fresh installs; there is no compatibility code for installs
from before fabric (core-template): those are rebuilt (2.1.1.20).
