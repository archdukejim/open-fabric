### 1.17.11.8.9 `convert_list(text, zone)`

| | |
|---|---|
| Purpose | convert a published DNS block list into a response policy zone (manual 1.12.2.6): hosts files, plain domains, RPZ as published, and AdGuard's DNS syntax — `\|\|name^` (the name and below), `@@\|\|name^`, `\|\|*.name^`, a whole TLD, `$denyallow`, `$dnsrewrite` to a name (a block), `$badfilter`, `$important`, `\|\|1.2.3.4^` (an rpz-ip trigger). | Inputs | text — the list as downloaded (str); zone — the zone's name (e.g. "<id>.list.rpz"). |
| Returns | {"zone_text": the zone file (str), "rules": rules converted (block + allow names + addresses), "records": RPZ records written, "skipped": rules skipped, "skipped_by_reason": {reason: count}}. |
| Fails | never (an empty or unusable list gives rules 0: the caller refuses it). |
| Feeds | dns_filter/update_lists; tests/resolver/run.py. |
| Notes | AdGuard's semantics (adguard-dns.io/kb/general/dns-filtering-syntax): a hosts line or a plain domain blocks the name only; `\|\|name^` the name and every name below it. An RPZ list as published (lines "name CNAME .") is read as plain domains: its wildcard lines become `*.name` blocks. |
| Called by | `fabriclib.dns_filter.update_lists.update_lists` |
