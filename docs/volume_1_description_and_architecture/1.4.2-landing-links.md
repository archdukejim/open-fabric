# 1.4.2 Landing page links

Topics:

## 1.4.2.1 Landing Page Links (`link-vars.yaml`)
The `link-vars.yaml` file (`<deploy_base_dir>/fabric/config/link-vars.yaml`; until it exists, the shipped `config/link-vars-template.yaml`) defines the dynamic list of quick links shown on the landing portal. It is managed interactively via `fabricctl` under the **Landing Page Links** menu.

### 1.4.2.1.1 `links`
**Description:** A list of dictionaries containing `name` and `link` keys for each quick link to display on the landing page. The `link` values can use Jinja variables like `{{ domain }}` or `{{ hostname_keycloak }}` which will be evaluated natively during deployment.

**Default Value:**
```yaml
links:
  - name: Keycloak (Admin)
    link: "sso.{{ domain }}/admin"
```

**Effected Jinja Templates:**
- `nginx/www/landing/index.html.j2`

## 1.4.2.2 Links from DNS records (0.6.1, 2.1.4.2)

The owner (2026-10-07): a name added to the site's zone, such as `host1.<domain>` for a Proxmox host, can appear on
the landing page as a link, beside the links of 1.4.2.1.

- **Only records marked for it** (2.1.4.2): an A, AAAA or CNAME record of the site's zone (`dns.dynamic_zone_var`) may
  carry `link: {label, port, path}`. Records without it (printers, switches, anything that is not a web page) are
  not listed.
- **The address:** `https://<name>.<domain>` with the record's `port` (e.g. 8006 for Proxmox VE) and `path` when
  set; `label` is the text shown (default: the name). Only https links are made.
- **Who sees them:** everyone on the LAN, like the rest of the landing page (no sign-in). Only marked records are
  listed, so the page never shows the zone as a whole.
- **Where it is set:** the web console's DNS page (*Add record*: *Show on the landing page*, with label, port and
  path; to change a link, delete the record and add it again) or the settings file (`link:` on the record).
  Validated with the record (`validate_record`): a label of up to 60 printable characters without `<`, `>`, `"` or a
  backslash, a port 1–65535, a path starting with `/` without spaces, quotes, backslashes or `<>`. Wildcard names
  are never listed. The mark is not part of the zone: BIND's zone file is the same with or without it.
- **When it shows:** the landing page is rendered by every apply, so a link appears or goes with the apply that
  changes its record. The links are listed as "This network", sorted by label, after fabric's own and before the
  `link-vars.yaml` links.
