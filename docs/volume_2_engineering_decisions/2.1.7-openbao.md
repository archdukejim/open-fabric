## 2.1.7.1 Secrets

- **Decision:** OpenBao, all four uses, auto-unseal from a local key file ([1.7.1.1](../volume_1_description_and_architecture/1.7.1-openbao.md#1711-secrets-openbao)).
- **Shapes:** 1.7
- **Made:** 2026-09-27 to 2026-10-01, while fabric was designed, by the owner.
- **Why:** one place for fabric's and applications' secrets, unlocked without a person at boot.
- **Status:** In force; the unseal part is refined by 2.1.7.2 (the key file is one slot among several). Built: fabric's secrets and apps KV; not built: rotated credentials, SSH CA.

## 2.1.7.2 How OpenBao is unlocked

- **Decision:** Key slots (local file, USB sticks, PKCS#11 security keys, KMIP HSMs); any one enabled slot unlocks; handled on the host by fabric-unlock; vendor-neutral ([1.7.1.1](../volume_1_description_and_architecture/1.7.1-openbao.md#1711-secrets-openbao)).
- **Shapes:** 1.7, 4.7
- **Made:** 2026-09-27 to 2026-10-01, while fabric was designed, by the owner.
- **Why:** a person chooses how strongly the vault is locked without fabric depending on one vendor's hardware.
- **Status:** In force.

## 2.1.7.3 Secrets (checklist E1)

- **Decision:** OpenBao for fabric's and applications' secrets; mode-0600 files at bootstrap; environment variables into containers; never the command line.
- **Shapes:** 1.7, 1.2
- **Made:** 2026-10-03 (the checklist), by the owner.
- **Why:** 2.3.1.8.5.
- **Status:** In force.

## 2.1.7.4 Keycloak's database password rotates monthly

- **Decision:** Postgres gets its own admin, separate from Keycloak's user; OpenBao's database engine rotates Keycloak's password monthly at night, then Keycloak is re-rendered and restarted; Postgres never depends on OpenBao to start; `fabricctl vault rotate-db` rotates now.
- **Shapes:** 1.7, 1.6
- **Made:** 2026-10-08, by the owner, for 0.6.3.
- **Why:** fewer long-lived secrets (2.3.1.11.9).
- **Status:** In force; being built for 0.6.3.

## 2.1.7.5 An SSH certificate authority for the domain's Linux machines

- **Decision:** OpenBao's SSH engine: 8-hour user certificates with the person's AD groups as principals (web console or `bao ssh`, `ssh:sign`), host certificates for joined machines, the join script trusting the user CA and the host CA (an option, on by default).
- **Shapes:** 1.7, 1.6, 4.6
- **Made:** 2026-10-08, by the owner, for 0.6.3.
- **Why:** 2.3.1.11.9.
- **Status:** In force; being built for 0.6.3.
