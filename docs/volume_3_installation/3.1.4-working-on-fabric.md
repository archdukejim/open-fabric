## 3.1.4.1 Branches, commits and merges

The global Rule 8 applies as it is: feature branches only, pushed after each commit; commits staged by explicit
path, saying why, ending with the co-author line of the tool that wrote them; the manual changed in the same commit
as the code it describes; only the owner merges to `main`, once every suite and CI are green. Moved from
`AGENTS.md` §7 on 2026-10-03.

## 3.1.4.2 Files in git

LF line endings everywhere, enforced by `.gitattributes`. No generated files (`__pycache__`, rendered output, test
output, `dist/`); the function reference (1.17) is the one generated part of the manual, kept current by
`tests/docs`.
