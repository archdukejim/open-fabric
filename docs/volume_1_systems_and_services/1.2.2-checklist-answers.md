## 1.2.2.1 How these were made

The owner's decision checklist (Rule 13) walked on 2026-10-03, most answers taken from decisions already made
while fabric was built (1.2.1). Recorded answers are rules for this repository, as binding as the global rules.
Each links to its reasoning in [5.5.1](../volume_5_notes_and_troubleshooting/5.5.1-checklist-reasoning.md).

## 1.2.2.2 The answers

| ID | Point | Decision |
|---|---|---|
| D26 | A1 Host product | Yes: fabric installs onto and changes hosts; Rule 12 applies |
| D27 | A2 UX variants | CLI (`fabricctl`) and web (Open Fabric), shipped together in one package; entry points `src/ux/cli` and `src/ux/web` |
| D28 | A3 Distributions | Ubuntu LTS only (24.04; 26.04 tested on the Pi), for hosts on amd64 and arm64; Debian 13 and Raspberry Pi OS dropped from D2 (owner, 2026-10-04) |
| D29 | A4 CPU architectures | amd64 and arm64 |
| D30 | A5 Tiers and licensing | No tiers: MIT, free |
| D31 | A6 Resource budget | A Raspberry Pi with 4 GB is the smallest target; every container has a memory limit (product design §7a) |
| D32 | B1 Languages | Python 3, Bash, Jinja2 templates; no framework forces a layout |
| D33 | B2 Packages | Single package, no import aliases |
| D34 | B3 Lint and typecheck | ruff (Python) and shellcheck (Bash) in CI and in the definition of done (the `lint` suite, 4.8.2.3: 120 characters per line except in tests); no typecheck while the code carries no type annotations |
| D35 | B4 CI | GitHub Actions |
| D36 | B5 Code documentation | Structured docstrings on every function (purpose, inputs, returns, failures, callers) and a generated function reference (1.11) |
| D37 | C1 Versions | Semantic versioning (`config/VERSION`, 1.5.0 at the time) |
| D38 | C2 Publishing | GitHub Releases for the `.deb`; fabric's images to a container registry (D41); a signed APT repository on GitHub Pages is planned (D7) |
| D39 | C3 Upgrade window | Upgrades from the previous fabric release; installs from before fabric (core-template) are rebuilt, never upgraded |
| D40 | C4 Image pinning | Every image pinned by digest (`images.lock.yaml`); a stale upstream image is built from a pinned base |
| D41 | C5 Packaging and build matrix | The host package stays a `.deb`; fabric's own eight images (adguard, bind9, dirsrv, freeradius, kea, keycloak, stepca, web UI) are built in CI from `packaging/` with one build-matrix file, multi-arch, published and pinned by digest; hosts pull them and `fabricctl images update` manages updates. Design: 5.1.4 (D80–D83). The build, smoke test and signed publishing are built (4.7.1, 2026-10-03); hosts using the published images is next (5.1.1.8) |
| D42 | D1 Service accounts | `fabric-*` names in the uid/gid band 600–649 |
| D43 | D2 Installed layout | `/opt/fabric`, `/opt/<service>`, `/etc/fabric`, `/usr/lib/fabricctl`; never dependent on the repository layout |
| D44 | D3 Uninstall and purge | Uninstall offers an export, then removes fabric's data and undoes its host changes; purge keeps downloaded images |
| D45 | D4 Offline installs | Required: a bundle path for everything that downloads |
| D46 | D5 Host changes | The groups packages, runtime, services, accounts, resolver, firewall, trust, time (2.7); unattended flags `--approve` / `--decline` |
| D47 | E1 Secrets | OpenBao for fabric's and applications' secrets; mode-0600 files at bootstrap; environment variables into containers; never the command line |
| D48 | E2 Identity | Keycloak (OIDC, TOTP enforced) on 389-DS; a client certificate from fabric's CA for the web UI |
| D49 | E3 Privileges | The root `fabric-agent` (Docker access), and each container's added capabilities: inventory recorded in 1.3 when it moves (open until then, 1.2.2.3) |
| D50 | E4 Relaxations | `security.firewall`, `security.docker_daemon_hardening`, declined host-change groups; shown in `fabricctl status` and the web UI |
| D51 | E5 Internal TLS | Yes, everywhere, verified against fabric's CA |
| D52 | F1 Integrations | None (the Cockpit bridge was dropped, 2.13); BIND, Kea, Keycloak and the others are fabric's own components |
| D53 | F2 Package sources | Host: the OS archive only (Docker as Ubuntu's `docker.io`). Images: the distribution's archive, plus an upstream's signed repository only where D22 needs a newer LTS than the distribution has (Kea 3.0) |
| D54 | F3 Licences | fabric is MIT. The `.deb` bundles only permissive libraries; fabric's images run distribution packages under their own licences (389-DS and Samba are GPL) as separate programs, accepted (owner 2026-10-03) |
| D55 | G1 Data | 389-DS, Postgres (Keycloak), OpenBao, BIND zones, Kea leases; changes through idempotent seeds and settings upgrades; backup and restore by `uninstall --export` / `restore` |
| D56 | H1 Test environments | WSL Ubuntu with Docker (amd64) and a test Raspberry Pi 5 (arm64); multi-site tests wait for the Windows lab hosts to be rebuilt (5.4) |
| D57 | H2 Mocks | SoftHSM2 and PyKMIP stand in for hardware security modules; nothing else is mocked |
| D58 | I1 Manual exports | None |
| D59 | I2 Deviations | One: the test layout (1.2.3) |
