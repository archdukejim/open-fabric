## 1.1.3.1 Phases

What each phase is; the order of what is left is the roadmap's ([1.1.4](1.1.4-roadmap.md)).

| Phase | Deliverable | Depends on |
|---|---|---|
| 0 ✅ | Rename to fabric, `fabricctl` (no migration: pre-fabric hosts are rebuilt) | — |
| 0.5 (mostly ✅) | Foundations: container hardening ✅, version lock with digest pinning ✅ (`config/images.lock.yaml`), LF line endings ✅, Pi preflight ✅; CI on arm64 + amd64 runs lint and builds and smoke tests fabric's images ✅; the real-container suites — not in CI (run by hand: `sudo tests/run-all.sh`) | — |
| 0.6 (superseded) | Signed image channels on GitHub Pages and a local registry: superseded by D41 (2026-10-03) — fabric's own images are built, signed and published in CI and pinned in the lock each release ships (2.6.3, 4.7.1); `fabricctl images update / rollback / prune` built; a `fabric-update` timer and offline export/import not built | 0.5 |
| 0.7 ✅ | OpenBao: container, unlock methods (key file, USB, PKCS#11), OIDC login via Keycloak for OpenBao's own UI, break glass, KV for fabric (secrets moved in) and apps | 0.5 |
| 0.8 (KMIP ✅) | OpenBao: KMIP unlock ✅ (tested against PyKMIP), rotated DB/LDAP credentials, SSH certificate CA (secrets are browsed in OpenBao's own UI) | 0.7 |
| 1 ✅ | Native installer `fabricctl setup` (all playbooks ported); Ansible removed | — |
| 2 (partly ✅) | `.deb` build ✅ (`package.yml`: every push, attached to the GitHub Release on a tag); `setup.sh` became `scripts/install-from-checkout.sh`, which installs through the same `.deb` ✅ (D25); signed apt repo and amd64 + arm64 test runs in CI — not built | 1 |
| 3 ✅ | Kea DHCP + DDNS + reservations (CLI + UI) | 2 |
| 4 (two passes ✅) | FreeRADIUS 802.1X: EAP-TLS, MAB, dynamic VLANs ✅; people by password (EAP-TTLS) ✅; RadSec, CoA, SCEP later | 3 (MAB uses reservations) |
| 5 (mostly ✅) | Web UI: PKI ✅ (sign, issue, inspect, convert, issued; no revocation), directory ✅ (devices, device roles, people), roles ✅ (RBAC, [1.5.5.1](1.5.5-rbac.md#1551-access-control-for-people-rbac-across-the-stack-decided-d19-built)), health (service status only; no doctor output or updates) | 3, 4 |

Each phase ships on its own and is tested the same way as 0.5.0: real
containers in CI (389-DS, Keycloak, Kea, FreeRADIUS with `eapol_test`).
*Today these suites exist under `tests/` and run by hand (`sudo tests/run-all.sh`);
CI builds the package, lints, and builds and smoke tests fabric's images.*
