## 4.9.1.1 Dev preview

To look at the pages without a CA, client certificate, Keycloak or a running install:

```bash
python3 src/ux/web/devserver.py            # from a checkout (needs python3-jinja2) -> http://127.0.0.1:8080
docker run --rm -p 127.0.0.1:8080:8080 --entrypoint /usr/bin/python3 \
    fabric/web:local /app/webui/devserver.py --bind 0.0.0.0     # from the image, on a fabric host
```

It renders the real pages (`src/webui/views`) with sample data (`src/webui/devpreview/`) under an orange **DEV PREVIEW** banner. `--as <bundle>` (e.g. `--as fabric-auditor`) shows the pages as that bundle sees them; the default is every permission. Changes work in memory only — there is no fabric-agent, nothing is saved, rendered or reloaded, and a restart resets everything. `/preview/denied` shows a refused sign-in. It is a separate entry point on purpose: the production server (`server.py`) has no dev switch, so a real install can never run without sign-in. It listens on 127.0.0.1 unless told otherwise; never expose it.
