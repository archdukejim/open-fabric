## 3.14.2.1 Lifecycle Commands

Every `fabricctl` subcommand (Python, `src/fabriclib/`; `sudo fabricctl --help` lists them). Setup and its steps are idempotent. See [install.md](../volume_4_infrequent_ops/4.1.3-running-setup.md#4131-run-the-installer) for setup's options and the step list.

| Command | What it does |
|---|---|
| `sudo fabricctl setup [--file vars.yaml]` | Install or re-converge. Re-run after changing settings. |
| `sudo fabricctl setup --step <name>` | Run one step, e.g. `--step firewall` after editing `security.firewall_allow` (`--list` shows the steps) |
| `sudo fabricctl status` | `fabric.target` and every unit: state and container health (changes nothing) |
| `sudo fabricctl start/stop/restart` | The whole stack through systemd `fabric.target`; prints the same table, then `fabric: <verb> done` |
| `sudo fabricctl doctor` | End-to-end checks of the running install (the `verify` step); exits 1 if any check fails |
| `sudo fabricctl tsig list/add/update/set-secret/rotate/remove` | TSIG keys for RFC2136 clients — see [TSIG Keys](3.2.2-tsig.md#3221-tsig-keys-rfc2136-dynamic-updates) |
| `sudo fabricctl acl list/add/remove/policy` | BIND ACLs and their update policies — see [ACLs](3.2.3-acls.md#3231-acls) |
| `sudo fabricctl dhcp status/leases/reserve/unreserve` | DHCP (Kea) — see [DHCP](3.4.1-dhcp.md#3411-dhcp-optional-kea) |
| `sudo fabricctl radius status/log/add-client/rotate-secret/remove-client/map-group/unmap-group` | 802.1X (FreeRADIUS) — see [802.1X](3.5.1-radius.md#3511-8021x-optional-freeradius) |
| `sudo fabricctl logs status` / `logs set-password elastic` | Log forwarding (Fluent Bit) — see [Log forwarding](3.12.1-log-forwarding.md#31211-log-forwarding-optional-fluent-bit) |
| `sudo fabricctl images status/update/rollback/prune` | Container images — see [`fabricctl images`](3.11.1-images.md#31111-fabricctl-images) |
| `sudo fabricctl federation status/enable/disable/invite/invitations/revoke/remove/reparent/relay` | Sites joining this install — see [Federation](3.9.1-federation.md#3911-federation-sites) |
| `sudo fabricctl vault …` | OpenBao and its unlock methods — see [OpenBao](3.10.1-openbao.md#31011-openbao-secrets) |
| `sudo fabricctl secrets list` / `secrets show <name>` | fabric's own secrets (in OpenBao); `show` is audited |
| `sudo fabricctl security` | The sign-in layers, and any lowered one (3.13.4) |
| `sudo fabricctl security raise <layer> [<value>]` | Raise a layer, as the web console's Security page does |
| `sudo fabricctl security lower <layer> [<value>]` | Lower a layer: asks for its name typed back (never `--yes`); audited; shown until raised again |
| `sudo fabricctl security kerberos on\|off` | Signing in with the domain logon |
| `sudo fabricctl client-cert <user> [--days N]` | Web UI client certificate for another admin (`~/fabric-admin/<user>.p12`, default 365 days) |
| `sudo fabricctl certs [--force]` | Renew service certificates (and `extra_certs`) that are missing, expiring within 30 days, missing a name or not from this CA (`--force`: all service certificates); restarts only the running services whose certificates changed |
| `sudo fabricctl reinstall [--yes]` | Uninstall + setup, keeping config, secrets, the CA, certificates and OpenBao (data and vault key). Directory users/groups and Keycloak's database are **not** kept; the first admin is re-created with a new login kit. Asks first unless `--yes` |
| `sudo fabricctl setup --undo <group>` | Revert one host change fabric made (`runtime`, `firewall`, `trust`, `time`, `resolver`) and record it as declined — see [install.md](../volume_4_infrequent_ops/4.1.3-running-setup.md#41313-changes-to-the-host-asked-first) |
| `sudo fabricctl uninstall` | Remove fabric (lists what happens to each host change, then asks: export all data to a folder you choose? purge the package too?); see [install.md](../volume_4_infrequent_ops/4.3.2-reinstall-uninstall.md#4321-reinstall--uninstall) |
| `sudo fabricctl restore <folder> [--yes]` | Bring back a fabric exported by `uninstall --export` (or `apt purge`); see [install.md](../volume_4_infrequent_ops/4.3.2-reinstall-uninstall.md#4321-reinstall--uninstall) |

`setup`, `reinstall`, `uninstall` and `restore` take `--deploy-base DIR` (as two words) for an install outside `/opt`; the package's `/usr/bin/fabricctl` runs every other command from `/opt/fabric`. An unknown command prints the list and exits 2.
