# 5.4.2 Known gaps

Topics:
- 5.4.2.1 Missing features
- 5.4.2.2 Documentation gaps

Moved from the repository's README on 2026-10-03 (global Rule 7.1: the README holds no design).

## 5.4.2.1 Missing features

- DNS-over-TLS (`:853`) is not exposed yet; there is no automated health check for DoH (`/dns-query`).
- No `fabricctl` command for people: they are added in the web UI (People), in the Keycloak admin console (writable
  LDAP federation) or with `ldapadd` (as `super_admin`/`user_creator_admin` over StartTLS or LDAPS).
- Signed offline image bundles (`fabricctl images export/import`) and the signed image channel are designed but not
  built yet (2.6; publishing fabric's own images is planned, D41).
- No scheduled certificate renewal, monitoring or alerting — service certificates are renewed by `fabricctl setup`
  or `fabricctl certs`.

## 5.4.2.2 Documentation gaps

- IPv6: zones can hold AAAA records (with ULA reverse zones), but `fabric_net` and the published ports are IPv4
  only; this is not described in one place.
